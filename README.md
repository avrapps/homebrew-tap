# avrapps/homebrew-tap

Homebrew tap for [Falcon PDF](https://falconpdf.com/) — a fast, lightweight PDF viewer and editor.

## Install

```sh
brew tap avrapps/tap
brew install --cask falcon-pdf
```

Or in one line:

```sh
brew install --cask avrapps/tap/falcon-pdf
```

## Update

```sh
brew update
brew upgrade --cask falcon-pdf
```

## Uninstall

```sh
brew uninstall --cask falcon-pdf
```

## Notes

- macOS 12 (Monterey) or later.
- Apple Silicon (arm64) only. Intel Macs are not supported by this build.
